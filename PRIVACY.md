# Политика конфиденциальности / Privacy Policy

Дата вступления в силу / Effective date: 21 August 2026

## Русский

EE71 Monitor работает локально в браузере пользователя.

- Расширение обращается только к HTTP-адресу мобильного роутера Alcatel EE71, который пользователь указывает в настройках.
- Расширение получает системные данные домашней страницы роутера, доступные без авторизации: заряд батареи, состояние сети и подключения, уровень сигнала, состояние Wi‑Fi и количество клиентов.
- Настройки и последний полученный статус сохраняются локально средствами хранилища браузера.
- Расширение не собирает аналитику, не использует рекламные идентификаторы, не продаёт данные и не отправляет данные роутера, историю браузера или персональную информацию разработчику либо сторонним сервисам.
- Разрешение на доступ к HTTP-адресу запрашивается только для указанного пользователем хоста. Его можно отозвать, удалив расширение или изменив разрешения в браузере.

Вопросы о конфиденциальности можно задать через [GitHub Issues](https://github.com/antiefa/EE71-Monitor/issues).

## English

EE71 Monitor operates locally in the user's browser.

- The extension connects only to the HTTP address of the Alcatel EE71 mobile router configured by the user.
- It reads system information exposed by the router home page without administrator authentication, including battery level, mobile network and connection state, signal strength, Wi-Fi state, and connected client counts.
- Settings and the most recently received router status are stored locally using browser storage.
- The extension does not collect analytics, use advertising identifiers, sell data, or transmit router data, browsing history, or personal information to the developer or third-party services.
- HTTP host access is requested only for the host entered by the user. The permission can be revoked by removing the extension or changing its browser permissions.

Privacy questions can be submitted through [GitHub Issues](https://github.com/antiefa/EE71-Monitor/issues).
